## 📖 專案簡介 (Project Overview)

現代環保自然葬（樹葬）雖解決了土地佔用問題，卻衍生出家屬**「尋址迷航」**與**「傳統擇位焦慮」**的痛點。

**Eternal Green** 是一個結合 B2B 園區智慧管理與 B2C 家屬數位追思的雙端平台。我們透過以下三大核心技術，致力於讓生命回歸土地，讓思念永存雲端：
1. **AI 命理精準擇位：** 將傳統干支曆法數位化，結合 GIS 方位權重，計算最高適配度的安葬區位。
2. **LBS 精準定位與 AR 導引：** 解決樹葬不立碑的痛點，利用定位技術與虛擬錨點重建祭祀儀式感。
3. **AIGC 數位紀念館：** 結合生成式 AI 模型，將思念轉化為永續的數位互動。

## 🛠️ 技術架構 (Tech Stack)
* **前端介面 (Frontend):** HTML5, CSS3, JavaScript (ES6+)
* **核心演算 (Algorithms):** Haversine 公式 (LBS 定位)、自建干支權重運算模組
* **UI/UX:** RWD 響應式設計、模擬 AR 雷達與 AIGC 非同步載入動畫
